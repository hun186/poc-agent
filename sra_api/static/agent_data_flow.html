代理人資料運用處理流程

說明 txt、SQL、Excel→SQL、Elasticsearch 與代理人回答之間的資料流向

RAG / Agent 使用者提問後，代理人會先到 Elasticsearch 檢索相關文本與結構化證據，再組合答案；ES 的內容來源包含既有 txt 匯入、SQL 匯入，以及後續新增的 Excel→SQL 匯入機制。

資料來源
匯入 / 轉換
Elasticsearch 檢索庫
代理人使用流程

1. 來源進入 ES

  • txt 透過文本匯入流程整理為可檢索內容。
  • SQL 來源表透過 SQL→ES 匯入流程索引到 Elasticsearch。

2. Excel 的新增路徑

  • Excel 不直接宣稱已成為 ES 文件；先經 Excel→SQL 上傳、預掃描與確認匯入。
  • 匯入 SQL 後再沿用 SQL→ES 的資料治理與索引流程。

3. 代理人查詢

  • 使用者提問時，代理人到 ES 檢索 evidence。
  • 回答時彙整 ES 命中的文本與結構化資料來源。
