使用者 Excel 匯入操作

上傳 Excel 後會先存入備查區；請先執行預掃描，確認預估新增、重複與錯誤列數後，再按「確認匯入 SQL」。若狀態為 imported_with_errors，請查看「錯誤診斷」欄與預掃描樣本。

建立 Excel→SQL 任務設定檔

提供資料庫管理權限（db_operator / superuser）的使用者可在此建立真正的 config/excel_to_sql/*.json 任務設定檔。建議優先選擇既有任務作為資料庫連線來源，系統會沿用其 DB 位址、帳密、加密與 ODBC driver 設定，避免業務使用者接觸敏感帳密。

欄位比對方式說明

  • 預設 / exact：Excel 標題必須與來源欄位完全相同，適合欄名穩定的表格。
  • prefix：Excel 標題以指定文字開頭即可，例如「船名1」「船名2」。
  • contains：Excel 標題包含指定文字即可，適合欄名前後常有附註文字時使用。
