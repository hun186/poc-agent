建立 Excel→SQL 任務設定檔

提供資料庫管理權限（db_operator / superuser）的使用者可在此建立真正的 config/excel_to_sql/*.json 任務設定檔。建議優先選擇既有任務作為資料庫連線來源，系統會沿用其 DB 位址、帳密、加密與 ODBC driver 設定，避免業務使用者接觸敏感帳密。

Excel 欄位對應

常用 SQL 型別小提醒（預設欄位型別與欄位對應 SQL 型別都可選擇或手動輸入）
  • NVARCHAR(255)：短文字，例如名稱、代碼、狀態。
  • NVARCHAR(MAX)：長文字，例如備註、描述、原文內容。
  • INT / BIGINT：整數；BIGINT 適合很大的流水號或計數。
  • DECIMAL(18,2)：精確小數，例如金額、重量、比例；括號可依需求調整。
  • FLOAT：近似小數，例如科學量測；不建議用於金額。
  • DATE / DATETIME2：日期 / 日期時間。
  • BIT：是 / 否、true / false 類欄位。

多欄位拼裝成 SQL 新欄位

可把多個 Excel 欄位拼成實際 SQL 欄位；模板可使用 {Excel欄名} 代入每列值，例如 日期是{日期}，發生地點是{地點}，當天的敘述是{敘述}。若不填模板，會用分隔字串串接來源欄位。SQL 新欄位請使用安全命名，例如 complete_description，不要使用空白。View 模式需待資料庫 view 管理流程確認後再開放。

安全提醒：新建任務預設為 pending，不會出現在上傳任務清單；必須由 superuser 審核啟用後才能正式上傳影響 SQL。

Superuser 任務審核 / 停用

只有 superuser 會看到此區塊；後端 API 也會強制檢查 superuser 權限。

欄位比對方式說明

  • 預設 / exact：Excel 標題必須與來源欄位完全相同，適合欄名穩定的表格。
  • prefix：Excel 標題以指定文字開頭即可，例如「船名1」「船名2」。
  • contains：Excel 標題包含指定文字即可，適合欄名前後常有附註文字時使用。
