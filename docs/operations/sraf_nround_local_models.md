# Deep report local model transport

The explicit LocalDeepModels adapter has one numeric loopback/RFC1918/IPv6 ULA Ollama endpoint and three operator-selected model IDs. No default provider, HTTP redirect, ambient proxy, cloud-tag model or retry. The Worker runtime must receive all three callables (plan, assess, report); synthesis uses the injected report callable, not the general model fallback. All stages are bounded at the call site; semantic calls receive remaining retrieval budget capped at 60 seconds. The provider uses bounded response bytes, explicit context/output limits and rejects truncated responses. The byte fence is conservative, not measured tokenization, and Requests timeouts plus deadline checks do not provide hard in-flight provider cancellation.

This is a candidate transport, not an enabled startup configuration or a guarantee of local execution: the operator must independently verify server ownership, model provenance, no server-side cloud forwarding, private transport/TLS and ES/index/whole-question authority. Report model must match the configured REPORT_MODEL_ID for report metadata consistency. No private provider, ES, or actual Linux call made by tests.
