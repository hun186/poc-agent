# SRAF 報告前 Evidence 文字量警示（離線契約）

## 背景

使用者曾發現：送到報告 LLM 的片段有時僅顯示「習近平會面某某人」，甚至只有日期。這樣的片段可能不足以支撐可靠的背景、分析與具體結論。但單純「字數少」並不必然代表片段無價值，因此本項只提出**限縮用語的提醒**，不得當成正確率、Recall、因果支撐或模型判斷。

## 精確範圍

新增 `assess_report_evidence_information`，只讀已準備提供 LLM 的 `ev[].note` 與 `ref_no`；最多評估 500 筆、每段 50,000 字元、總計 2 百萬字元，輸出固定 `status` 與安全的計數（段數、非空白字元總數、32 字元以下片段數、全日期片段數），**不輸出原文、uuid 或日期值**。

`limited_text` 僅表示少量／過短的機械訊號：
- 全部片段都是純日期。
- 只有一、二段且合計可見字元少於 120 字元。
- 最多四段，且每段都少於 32 可見字元。

其他資料狀態只標記 `measured_only`，不可宣稱 Evidence「已足夠」；無證據由 #483 零證據 guard 處置；超限或不合規回傳 `not_assessed`，不得誤報沒有風險。

## 部署狀態

此 PR **只建立離線機械檢核與單元測試，不接入正式 SRAF Report Agent、Word 或 N-round Worker**；不過濾或補抓任何 Evidence、不增加模型或 ES 呼叫，不會改變目前報告結果。接入與進階品質調校需另行審查，並驗證真實新聞與 LLM 生成品質。
