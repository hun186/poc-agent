# AI 自動化蒐情：從人工蒐整到「蒐情文明等級升級」

## 一、影片核心概念

這支影片要介紹一種新的 AI 自動化資訊蒐集、檢索、分析與報告流程。

核心概念不是單純：

> 「用 AI 幫忙寫報告。」

而是：

> **把過去高度依賴人工、耗費大量時間的資訊蒐集與分析流程，轉變成由 AI Agent 主動操作資料庫、反覆檢索、篩選、交叉分析、驗證證據並產生研析成果的自動化流程。**

這代表的不是單一工具升級，而是一種「資訊蒐集與分析生產方式」的改變。

過去：

**人操作資料 → 人搜尋 → 人閱讀 → 人整理 → 人比較 → 人分析 → 人寫報告**

現在逐漸可以變成：

**人提出情報目標 → AI Agent 操作資料與工具 → AI 搜尋 → AI 閱讀 → AI 交叉檢索 → AI 整理 → AI 分析 → AI 產生初步研析成果 → 人進行判斷與決策**

因此可以幽默地稱為：

# 「蒐情文明等級升級」

# 二十一、Elasticsearch 結構化資料

主要事件資料位於：

`multidim_event_json`

其中可包含：

### Event
事件主體、客體、行動、時間、地點、後果、關係等。

### Person
人物、角色、行動、發言、立場與關係。

### Involved Parties
參與事件的國家、政府、企業、機構或組織。

### Impact
事件可能造成的影響。

### Event Timeline
事件演變的時間線。

### Evidence Snippets
支持結構化資訊的原始證據片段。

因此 AI Agent 不必只依關鍵字搜尋整篇文章，而能利用事件結構進行更精細的資訊探索。

# 二十三、影片必須避免的錯誤表述

不要宣稱：

「AI 可以完全取代情報分析人員。」

應改為：

> AI 可以大量自動化過去耗費人工的資訊蒐集、整理、檢索與初步分析工作，使研究人員能將更多時間投入高價值判斷。

不要宣稱：

「AI 永遠不會漏掉資料。」

應說：

> Agentic Retrieval 有機會透過多輪檢索與 fallback strategy，降低單次關鍵字搜尋造成的遺漏。

不要宣稱：

「AI 產生的分析一定正確。」

應說：

> 重要結論仍需要證據追溯與人的判斷。

# 二十四、影片希望傳達的五個核心訊息

1. **AI Agent 的價值不只是生成文字，而是可以主動操作資料與工具。**

2. **Elasticsearch + MCP + LLM Agent 可以形成多輪智慧檢索流程。**

3. **從一次搜尋升級成「搜尋—觀察—調整—再搜尋」是關鍵改變。**

4. **大量人工資訊整理工作有機會被自動化，人力轉向分析、判斷與決策。**

5. **這種生產方式的改變，可以幽默地稱為「蒐情文明等級提升」。**
